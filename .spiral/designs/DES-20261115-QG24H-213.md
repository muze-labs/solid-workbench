Specification check during integration review:
- Solid Protocol, published Draft Community Group Report 12 May 2024,
  https://solidproject.org/TR/2024/protocol-20240512#writing-resources:
  Solid servers support PUT; container containment/resource metadata must not
  be updated through ordinary PUT bodies. Conditional Update encourages
  If-None-Match:* for creation; retain it as the app's no-overwrite contract.
- LDP 1.0, https://www.w3.org/TR/ldp/#ldpc-PUT: PUT is optional in general LDP,
  unlike Solid's profile. Do not extrapolate Solid requirements to every LDP
  server. Keep BasicContainer interaction metadata and trailing-slash target.
- Fetch https://fetch.spec.whatwg.org/#body-unusable: direct retrieval timed out;
  prior EVD208 retained the checked request/replay distinction. Current cycle
  verifies the published replay behavior through configured Chrome requests,
  rather than changing stream usability rules in Workbench.
- An empty string is a valid empty Turtle graph. The explicit Turtle media type
  remains necessary in this client composition; the fixture asserts it along
  with zero bytes, conditional creation and BasicContainer Link metadata.
