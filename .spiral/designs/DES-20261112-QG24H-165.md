# Use supplied icon artwork in existing app surfaces

Copy exact supplied SVG/ICO/32px PNG artwork into the four app source trees;
keep build-time favicon markup explicit and publish through the existing build.
Manifest images point to app icon.svg. Update default Files seeding. In the
editable shortcut projection, map only known built-in default Feather artwork
for the matching local app to its current icon, including cached existing rows;
leave native RDF and all explicit override/external icons untouched. Use a neutral
surface backing for image artwork; Feather action icons keep their treatment.
Verify both default and custom rows, SVG/ICO response bytes, phone/theme/photo
contrast, focus, reload and loaded-cache/offline behavior. No new app scope.

Specification review: HTML Living Standard rel=icon,
https://html.spec.whatwg.org/multipage/links.html#rel-icon (2026-11-12).
Declare actual PNG/ICO dimensions and sizes=any for SVG; browsers choose by
type/media/size, so test resource availability rather than assume one fallback
is always downloaded. No apple-touch/PWA install-icon support is claimed.
