# Participation without browser launch policy

Reuse PortConnection and native restoration envelope validation without another
transport. Introduce CapabilityParticipant in the existing dependency-free
capabilities module: explicit MessagePort connect with restoration identity/state,
registration, readiness/error reporting, capability requests/results/cancellation,
checkpoint/publication and embedded view dispatch. Constructing it must not read
browser globals or attach global listeners. The integrator owns the authenticated
window/port handshake; a port is authority only after that validation.

ManagedApp becomes the Workbench browser adapter using that same participant.
It retains opener/parent selection, task URL convention, resume session storage,
window/source/origin validation, presentation/focus messages, host navigation,
preference capability policy and broker embedding methods. Preserve existing
exports and wire frames. Independent browser provider uses explicit source/origin
checks and the participant, with no shell/framework/Metro/RDF library dependency.
Raw-wire peers stay separate to detect shared-client assumptions.

Shared close semantics preserve provider-owned unsaved edits: disconnected or
failed-startup state is not permission to discard an already-started editor.
Account/HTTP/storage remains outside the participant. Native Turtle plus optional
opaque string is the existing restoration envelope; no new persistence schema.
No published external specification is implemented by this private experimental
protocol. Governing references: broker roadmap, managed-workspace, resource-picker
and embedded app-view designs; retain v1 shape/authority boundaries. Browser native
MessagePort framing is unchanged. Muze engineering/library stewardship shape the
small explicit responsibility, no new package or generic service framework.

Implementation choice: keep the participant and adapter in the existing single
capabilities module, with no runtime imports. A new package or file-only transport
extraction would not remove constructor assumptions. ManagedApp inherits the
participation API and keeps its browser overrides. This is a bounded proof before
any publishing decision. Keep early channel retirement before resume-storage
writes, and reject continuation of retired registration/context work before
restoration. EVD239 records the correction and observable regression.


The maintainer's format concern is retained as deferred RSK240. Current protocol
and native Turtle state remain unchanged; a future consumer/format investigation
must precede any format/version change. SRC236 at 3d90e6c retains that source.
