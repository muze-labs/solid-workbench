# SimplyFlow 0.10.6 adoption evidence

The verified working branch is
`spiral/CYC-20261119-QG24H-295-simplyflow-adoption`, based on `d1a6c8e`.
Verification applies to the [implementation](../implementations/IMP-20261119-QG24H-297.md)
at `c212db34c2c8a4c9131cd73a1bc92016ffba6013`.

## Source, builds and transfer size

`npm run check` passed all 368 tests across 42 source files and built both the
readable and minified suites. Comparing complete minified JavaScript
graphs, including the auth callback, showed increases of 4202 to 4351
gzip bytes per app. Selected measurements are below.

| App | Baseline gzip bytes | Cycle gzip bytes |
| --- | ---: | ---: |
| Launcher | 155956 | 160270 |
| Contacts | 130547 | 134873 |
| Presenter | 163708 | 167910 |
| Documents | 727377 | 731709 |

Documents remains the only minified graph above the advisory download
goal. The readable build also emits warnings, including a new warning
for Profile. The 81 optional authoring files total 186898 gzip bytes.
The build and the live replacement fixtures check that normal startup
does not request those files.

## Focused Chrome evidence

The production Presenter fixture reconstructed and installed the Cobalt
thumbnail transformer at its public runtime slot, then restored it.
The open editor, local draft, loaded deck and native RDF survived.
The fixture checked row reuse after keyboard reordering, correct command
identity, phone focus, editing after provider restart, managed disconnect
and loaded-offline editing. Workbench keeps a Presenter focus retry for
controls that may remain disabled after bindings have settled.

The cold 390 by 844 Presenter fixture reached the first editable slide
at 27265 ms with 1377283 bytes over 23 requests, including frame resources.
It ran at 50 KiB/s down, 25 KiB/s up and 150 ms latency. The previous
version reached that task at 26750 ms with 1351925 bytes over 23 requests.
These are single fixture measurements including HTML, CSS and other
requested resources. Browser automation covers keyboard and touch
interaction. A physical device, manual assistive technology and a live
Solid issuer were outside this evaluation.

With a cached address book and a warm independent caller, the throttled
Contacts picker reached usable selection at 11963 ms. It transferred 569774
bytes over eight requests. The preceding cycle measured 10997 ms and 556956
bytes over the same request count and network profile. The fixture also
passed phone keyboard selection, reload recovery, focus return and offline
selection without writing sharing targets or permissions.

The integrated browser run caught a binding compatibility issue in the
shared account dialog. An unmarked app-level API map replaced component
entries, including dialog animation state. Marking only the Workbench
definition maps restored the dialog. The browser event fixture verifies
that inherited event fields survive a partial override and that a service
retains its identity. The suite still relies on Workbench's event adapter
for listening to external targets.

The combined browser run passed through Presenter collections and stopped
while opening the Files settings contribution inside Preferences. The
exact baseline passed the stock cold fixture. The current build reproduced
the cancellation in isolation and at a higher download rate. The browser
trace identified a startup exception in the child frame. The shell supplied
an undefined `suite-account` override, which replaced precomposed markup with
literal text and failed the library's new single-root contract. The shell
now preserves the build-time template when there is no override.
The stock fixture passed against the final build, including save and reopen,
cross-origin contribution, draft veto and phone layouts. The cold
50 KiB/s path reached usable settings in 35363 ms with 1849457 transferred
bytes over 26 requests. The exact baseline measured 34499 ms and 1810768
bytes over the same request count.

The independent Launcher catalog fixture passed native phone and desktop
navigation, search, offline reload, Escape and focus return. The independent
Launcher groups fixture passed the live group reader replacement and then
timed out waiting for the Previous button during phone paging. A fresh build
of the exact starting commit with its original npm lockfile reproduced the
same assertion on retry. Its first attempt reached a later keyboard focus
assertion.

The independent Documents fixture reproduced the previously recorded
default-zoom fit failure. The PDF scroller reported 788 pixels of content
in a 748-pixel viewport. The exact starting commit reproduced the same
failure and dimensions on retry. A disposable current-build probe
skipping only that assertion passed the remaining PDF navigation,
annotation editing, HTML rendering and reload recovery checks. The stock
fixture is unchanged. Shortcut metadata passed independently.
The phone-sized and desktop layout fixtures passed for all ten apps,
and the independent design-component fixture passed.

The new cycle, source and implementation Turtle companions parse and pass
the Spiral SHACL shapes. The worktree-wide validator still fails on relative
manifest and catalog IRIs resolved against opaque URN bases, as recorded
in [EVD293](EVD-20261119-QG24H-293.md).
