# Presenter live-template evidence

The verified branch is
`spiral/CYC-20261119-QG24H-300-presenter-live-template`, based on `c194fa6`.
Verification applies to the [implementation](../implementations/IMP-20261119-QG24H-302.md)
at `42ba05eacd4c191a87dbfeb0e535b82971297a58`.

## Source, build and downloads

`npm run check` passed 368 tests and both builds. Presenter's complete
minified JavaScript graph including the auth callback measured 167895 gzip
bytes, down from 167910. The authoring files total 186911 gzip bytes, up 13.
They remain opt-in. The throttled Chrome fixture measured 27238 ms and
1376783 bytes over 23 requests to edit a slide on a 390-by-844 viewport.
The preceding cycle measured 27265 ms and 1377283 bytes over 23 requests.
Both used 50 KiB/s down, 25 KiB/s up and 150 ms latency. Startup reached
the same task before the live-template check ran.

## Focused Chrome verification

The full Presenter fixture passed. A valid HTML override added a visible
label to both rendered thumbnails. Reverting to the authored entry removed
both labels. At both steps the existing deck, serialized RDF, selected
slide, slide order, editor frame and open draft survived. The fixture
counted zero additional Pod writes. The focused-row guard preserved the
existing button until the caller moved focus away. After each rerender the
caller restored focus to the thumbnail with the same native slide ID.
Other checks passed for provider restart, native touch and keyboard
editing, conditional conflict, and loaded-offline autosave. Manual
assistive technology and a physical device remain outside this evidence.

## Named-template discovery

A disposable Chrome probe verified the effective runtime entry and that
the named definition inside the app can refresh rows in the same app.
Normal generated roots do not expose their source template as
`data-simply-template`. The generated root's source is tracked internally
by SimplyFlow. The current proof uses Presenter's explicitly linked filmstrip
and the named template within its owning app.
The maintainer approved [scoping the marker separately](../../design/simplyflow-lifecycle-composition-design.md#scoped-follow-up-for-rendered-template-names).

## Suite verification

The combined browser run passed through Workspaces and stopped during the
provider fixture when Chrome DevTools reported "Promise was collected".
The same provider fixture passed independently. The recipient fixture
reported an alternate disconnection message on its first independent run
and passed on retry. The remaining independent fixtures passed except
Launcher phone paging and Documents default-zoom page fit. Both hit the
assertions reproduced in the [CYC295 baseline](EVD-20261119-QG24H-298.md).
The exact final Presenter fixture passed, including the throttled cold
start above. Cycle, source and implementation Turtle passed Spiral SHACL
validation.
