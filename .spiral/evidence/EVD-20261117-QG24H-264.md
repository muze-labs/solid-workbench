worker: **707230 gzip bytes**, above the advisory 200000-byte target. Readable
variant: 984449 bytes. Builds/dev remain usable; these are warnings, never gates.

A cold uncompressed HTTP fixture at Chrome's 125 KiB/s download, 50 KiB/s upload
and 150 ms latency measured 9995 ms / 2505173 body bytes / 12 requests to the
first rendered PDF page, and 10560 ms / 2533284 bytes / 15 requests to the first
annotation editor. This measurement predates the last small recovery/guard
refinements; final static totals above include them. It is not a gzip/CDN or
real mobile-network claim. Log: `/tmp/cyc260-cold.log`.

PDFs are fully read up to 32 MiB. Browser-readable remote access, including CORS,
is required; no proxy is introduced. Annotations and editor drafts persist on
the device. Cold-offline shell/engine/PDF installation, uncached-font availability,
password prompts, sharing-permission UI, conflict merging and real-provider
OIDC-expiry certification remain outside the delivered contract. Existing folder
permissions apply to explicit Pod publication; local personal defaults do not
claim a remote resource is private. Files detects .pdf paths; opaque PDF URLs can
be opened directly in Documents rather than claiming MIME-negotiated routing.

Using the existing validation venv exposes the known nonhierarchical URN-base
parser failure on relative manifest IRIs, including unchanged manifests. The
new cycle Turtle files parse with rdflib. Draft EVD RDF intentionally still lacks
its required immutable `verifies` reference: IMP263 is uncommitted and commits
are not authorized yet. No hash or approval is invented to make SHACL pass.
Pin the causal references through semantic commits, then rerun prospective
integration validation after human acceptance authorizes delivery. These are
