verify exact UTF-8 module strings, function/event reconstruction, origins,
re-export identity, changed-source hashes, old-version preservation, executable
runtime behavior and absence of authoring assets from normal static/dynamic
chunk imports. Native browser authoring fixtures explicitly import sources and
verify existing separate-host feature overrides and source reconstruction.

npm run test:browser passed its first nine suites through Files/Viewer, then
stopped in unchanged Presenter native click coverage at
presenter-browser.mjs:332: Slide did not receive click. Prior accepted-cycle
runs also failed at this location or :658. This remains an unclassified test
limitation; this cycle neither establishes nor fixes a demonstrated user defect.

/tmp/lean-runtime-browser.log. Unit/build log: /tmp/lean-runtime-check.log.

zero requests to them. Shared checks cover existing phone, focus/keyboard,
reload, offline, authenticated data and failure/recovery workflows; these are
automated evidence, not a new manual assistive-technology review.

transfer fell from 1427881 to 1176925 B with 17 requests; elapsed time changed
from 28254 to 23256 ms. This measures the native fixture, not compressed
production network performance. HTML/CSS/fonts/images remain in the observed
