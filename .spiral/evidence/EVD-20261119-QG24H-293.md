  builds. An AST audit of application and workspace module source found

  from normal startup requests. The current optional assets total 186825

  aggregate validator still rejects existing relative manifest/catalog IRIs

## Browser

The initial integration run found a remaining shared Profile projection
binding to its former injected jaqt API. Changing the projection to
`jaqt.from` resolved it. The next integrated run passed the four-app
scenario and the live Contacts proof, then exposed OLDM's default entry
overwriting the global in the Node side of the managed-browser fixture.
The browser command now invokes the existing Turtle loader for Node
fixtures which directly consume the Workbench RDF APIs.

The Contacts proof executes independently reconstructed search and data
helper source in a running production app, restores the original behavior
and checks the model, opened draft and native RDF identity. The full
inventory of replaceable app-owned functions, physical-device and manual
assistive-technology checks, and live Solid issuer verification remain open.

The combined browser run passed the Contacts proof and continued through
managed workspaces, the picker, session and Preferences. It stopped at the
Workspace diagnostics dialog timing assertion. The exact Workspace scenario
passed when run by itself. The remaining scenarios then ran individually.
Documents initially stopped during startup because four model effects used
the removed `host.documentsApi` dependency. A short Chrome probe captured
the exception. The Documents correction uses the globals for those effects
and for parsing the author profile. The first corrected run reached the
later page-fit assertion and reported a 788-pixel scroll height in a
748-pixel viewport, the same error and dimensions reproduced on main during
[CYC282](EVD-20261118-QG24H-284.md). A fresh build of this cycle's exact
base `30c246a` reproduced the error and dimensions. A temporary probe that
skipped only that known fixture condition passed the remaining Documents
checks for PDF rendering, editing, HTML display and reload recovery. All
other browser scenarios passed across the combined and individual runs.

Two throttled Documents runs reached the first PDF page at about 11.1 seconds
and opened the annotation editor at about 11.7 seconds. Chrome DevTools then
reported `Promise was collected` later in both runs. The throttled exact-base
run completed. The later throttled reader behavior remains unverified on the
cycle branch.

The slow-network phone Contacts picker used a cached address book with a
warm independent caller. The accepted baseline reached usable selection
after 10995 ms and transferred 554305 bytes over eight requests. The current
build reached selection in 10997 ms and transferred 556956 bytes over eight
requests. Both runs used 50 KiB/s down, 25 KiB/s up and 150 ms latency.
The difference in elapsed time is below the precision of this comparison.

## Launcher and Presenter extension

`npm run check` passed all 42 test files and the build. The Launcher fixture
reconstructed the membership reader from its version-matched module source.
A caller retained before replacement picked up the new reader and rejected a
move before writing RDF. Restoration through the same caller preserved the
graph serialization. The Launcher browser suite also passed native drag,
keyboard, Pod sync and loaded-offline checks. Its first attempt stopped at a
phone paging assertion before reaching the proof. The retry passed.

The Presenter fixture reconstructed the Cobalt thumbnail transformer from
its version-matched component source. The replacement rendered on the next
bound value change and the restored original rendered after another update.
The open editor and draft, active deck instance and native RDF were preserved.
Both proofs checked that ordinary use had made zero authoring-source requests
before explicitly loading the relevant source. The initial Presenter probe
exposed the difference between the original definition API and the merged
live API. The bridge now resolves the live app. The complete focused
Presenter browser suite passed with throttling.

Relative to the preceding cycle build, the complete minified graph including
the auth callback grew by 72 gzip bytes for Launcher and 81 for Presenter.
Optional authoring output gained one file and increased by 639 gzip bytes.
The throttled Presenter fixture reached an editable slide after
26750 ms and transferred 1351925 bytes over 23 requests. The preceding cycle
run took 26752 ms and transferred 1351692 bytes over the same 23 requests.

The combined browser run passed both replacement proofs and stopped at the
Launcher phone paging assertion after activating Next. This assertion already
failed on archived main during [CYC260](EVD-20261117-QG24H-264.md).
