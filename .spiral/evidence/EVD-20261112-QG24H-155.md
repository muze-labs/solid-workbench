## Supported behavior verified before final suite run

The existing main browser suite now passes including a still-live Profile draft
retained after forced broker disconnection and explicit discard. The next run
then found managed-browser.mjs still clicking the removed per-instance grant
checkbox; remove that obsolete fixture step. Its remaining workspace/selection
checks pass unchanged. A new large-checkpoint test initially lacked its sameGraph
import; correct that test import. Final npm run check then passes 26 test files
and both readable/minified builds (log /tmp/cyc151-check.log).

The subsequent seven-suite continuation passes managed, picker, session,
preferences, workspaces, provider and recipient browser checks, exit 0. Added
provider scenarios use the actual Workbench presenter with (1) cross-origin SDK
reload, (2) independent raw provider navigation with no disconnect notification,
and explicit reopening after failure. Both release broker tasks and retain the
previous resource, without replay. Existing separate-tab fallback and ordinary
result/cancellation still pass. Independent peers are callers/providers, not an
independently implemented broker.

The real managed Files caller changes its recipient, then its Contacts iframe
reloads. Files retains the previous native recipient ID/name, stops waiting,
and the Workbench broker no longer holds the old ticket. At 390x844, native
keyboard Enter closes the interruption dialog, returns focus to Change recipient
and starts a new selection; cancellation retains the previous person. Inspected
/tmp/cyc151-recipient-interrupted-phone.png: wrapped status text and accessible
native close control remain visible without horizontal overflow. Existing
recipient tests retain offline loaded-book selection, original RDF and
source-document access. No sharing-target/permission writes occur.

Source tests additionally verify cooperative remote closure of timeout:null
calls, active-handler abort/cleanup, malformed-envelope rejection, independent
structured-clone/Map payloads above 64 KiB, owner-slot release without replay,
retired grant RDF preservation, large native states and selected descriptions,
and large checkpoint local recovery plus explicit conditional save. Existing
source/origin/owner/provider-ticket, cancellation and state-preservation tests
remain. These assertions do not certify arbitrary peer failure or resource use.

assumed disposable merely because the broker connection failed.
