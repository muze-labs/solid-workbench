# Lean runtime packaging implementation

CYC187 implementation is ready for evaluation on its dedicated branch; no
commit, integration or human acceptance is claimed.

The existing Rollup editableSources plugin emits component entry metadata and
explicit inspection-only module strings into content-hashed authoring assets.
Runtime definitions keep component URL descriptors and module sourceUrl fields.
Rollup file references resolve these URLs without importing or requesting them.
Normal executable functions, SimplyFlow feature datasets, templates and styles
remain in the runtime. Ordinary text imports retain their exact UTF-8 contract.

Files, Launcher and Presenter identify inspection-only JavaScript with ?source.
Both readable and minified builds emit the same optional authoring assets under
assets/authoring. The build reports optional bytes separately from every full
normal app graph including required shared chunks and auth callback.

Unit coverage checks source fidelity, event/function reconstruction, re-export
identity, content-hash changes and ordinary runtime execution before source
loading. Both bundle variants retain isolated normal graphs. Browser authoring
fixtures explicitly load source only after asserting none was requested during
startup. Normal Files/Viewer, catalog and styling fixtures deny authoring routes.
Production has no equivalent loader, new renderer, transport or dependencies.

AGENTS.md, Moldable Solid Apps and README record the maintainer's prospective
source-distribution policy change. Source maps remain separate. EVD191 contains
measurements, successful checks and the unchanged Presenter test limitation.

Lineage is limited to build composition and source-definition changes governed
by IMP97, IMP109 and IMP0GSCX2 at the exact main baseline. Their unrelated event,
preferences and other behavior is retained. DES83's strict import partition
continues to constrain this implementation. The new design supersedes inline
readable-source distribution while preserving executable feature editing and
text-import semantics. This is a mixed change: runtime source metadata changes
contract; normal user workflows retain behavior. EVD191 tests both claims.
