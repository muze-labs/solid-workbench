# Consume SimplyFlow 0.10.6 in Workbench

[Cycle CYC-20261119-QG24H-295](../cycles/CYC-20261119-QG24H-295.md)
upgrades the suite to the npm release. The lockfile resolves the app package
to 0.10.5, bind and state to 0.10.3, and model to 0.10.4.

Models use their built-in reactive input and destroy method. The app
definition supplies a destroy hook that releases component event listeners
and calls the app's cleanup action. The definition registers Workbench API
maps, event maps and individual event descriptors with `simply.mergeable`.
API entries such as services and their state retain their identity. Partial
event overrides retain inherited descriptor fields. Feature inspection reads
the original app definition from `app.components.app`.

The shared shell keeps its build-time account template when the app supplies
no override. Files settings uses that path. Passing an undefined override
would replace the template with text and break SimplyFlow's single-root
validation before the settings app starts.

Presenter registers its thumbnail transformer directly on the component and
reads the owning app through the binding's `this.app`. Slides use their
native IDs as list keys, so Presenter can create fresh projection rows when
the deck changes. Presenter and Launcher wait for the binding before
scrolling to or focusing rendered content. Presenter still retries focus on
controls that can remain disabled during external work.

The work revises the Presenter integration in
[IMP-20261119-QG24H-292](IMP-20261119-QG24H-292.md).
