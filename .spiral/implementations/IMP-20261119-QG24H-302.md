# Register Presenter's editable thumbnail template

The Presenter component exposes the authored thumbnail under
`muze-solid-presenter-thumbnail`. The filmstrip references it through
SimplyFlow's scoped `rel` lookup. Both the precomposed page and the runtime
definition use the same HTML file. The list still uses native slide IDs.

The browser proof opens two slides and applies an in-memory edit through the
effective template entry and the installed template element. It calls
`binding.rerender()` on the filmstrip and awaits `binding.whenIdle()`.
Undo restores the authored component entry. The fixture tests refusal to
rerender with a focused thumbnail, moves focus temporarily to a stable
toolbar control and restores it by slide ID after each refresh. Presenter
itself requires only the named template and reference.
