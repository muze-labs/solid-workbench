# Web shortcut discovery

The Launcher saves ordinary HTTP(S) links as native RDF shortcuts. Drops
use the screen's existing destination and insertion marker. Add manually
offers the same action without drag and allows local-only addition. An ordinary
web shortcut preserves the URL and opens without a Workbench opener or launch
context. A compatible cross-origin Workbench app can still use the existing
explicit Fragment or Query launch mode. Existing stored shortcuts keep their
declared or default launch behavior.

The shortcut metadata capability uses the existing per-WebID provider
preference, with a same-origin deployment endpoint when unset. The dedicated
HTTP request uses the configured non-Solid Metro client. Lookup starts after
local persistence. Requests carry no credentials and strip the launch
fragment. Delayed replies check workspace, identity, URL and field ownership.
A failed icon request falls back to the existing sprite. The Rust service
continues to run in its separate repository with credential-free wildcard CORS
and an optional exact-origin setting.
