# Shared capability invocation reliability and simplification

Implemented on verified spiral/CYC-20261112-QG24H-151-capability-reliability,
from accepted main 4b6672096f78ce296f03cbc1fe2c960966f4493e. SRC152 confirms
scope; DES153 records design and size-policy reasoning. The scope/design delivery version is
5c0b47fb076b27854b04318f61a91c8287912af1; companion Turtle records the exact references.

PortConnection validates call/reply/cancel envelopes and recognizes an explicit
disconnect frame. Closing settles local work, notifies cooperative peers and
clears active controllers; replies after cancellation/close do not apply.
Structured-clone payload support remains independent of JSON/domain validation.
The shared presenter detects repeated iframe loads and changed provider
readiness generations. It ends the old ticket, shows close/retry guidance and
never replays an invocation. Broker disconnect errors release the owner's task
slot, including failures while waiting for readiness. Explicit reopening creates
a fresh ticket. User deliberation still has no inactivity deadline.

A disconnected but still-visible editor retains its draft and explicit discard
guard. Actual navigation/reload uses a separate recovery state. Initial
about:blank loads are ignored; later navigation remains an interruption. The
existing SimplyFlow attributes transformer compares attribute values before
setting them, so the status update keeps the original src attribute without
forcing another navigation. Rendering stays in SimplyFlow; no second renderer,
network mechanism, library wrapper or dependency is introduced.

Remove Launcher chooseFiles, its editable module/API exposure, the broker's
live request/allow/authorize route, ManagedApp.request, grant controls and Files-
specific auto-grant detection. Update internal fixtures to exercise configured
transient tasks and the remaining editable provider-resolver action. Managed
window restoration/checkpoint/session behavior remains supported. Stop reading,
writing and comparing allowBrowse in workspace projections; its native RDF is
preserved as unowned data, even when its value is not a supported boolean.

Remove inherited 65536-byte JSON/native-state and 60000-byte recipient checks.
Retain interpreted-field validation, native RDF preservation, selected-subject
export, unsupported-structure refusal, active-call counts and nesting guards.
The HTTP background-save keepalive safeguard remains separate; large native
state persists locally and can be saved explicitly with conditional requests.

EVD155 records source, protocol, browser, preservation and download evidence.
No new user-facing feature or capability semantics, iframe Escape fix, package
publication, human acceptance or integration is claimed.
