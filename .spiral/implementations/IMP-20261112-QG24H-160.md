# Iframe Escape repair

Implements DES159 under confirmed CYC157/SRC158 on the dedicated cycle branch.
The shared capability component declares an editable SimplyFlow window keydown
action. Unconsumed Escape requests scoped presentation closure; native local
modal/popover handling, composition and key repeat retain priority. ManagedApp
sends current id/key only to its captured host origin for embedded ready tasks,
including a still-visible disconnected editor. The host validates exact source,
origin and active ticket and reuses its existing close guard. Late guard replies
cannot modify a replacement invocation. Account keeps its private-port route
and gains the same local-layer checks.

Launcher keeps its picker invoker focusable with aria-disabled while its existing
selection guard prevents duplicate calls. This restores native focus after close.
No new dependencies, HTTP calls, data writes, renderer or broker methods.
Tests exercise native keyboard input, real providers, independent cross-origin
messages, close guard/data preservation and retained invocation isolation.

Delivery authorized by the maintainer after review. Companion Turtle pins the
source design and the preceding shared presentation implementation (IMP154).
This adds presentation behavior to that unit; its accepted routing, disconnect
and payload-policy semantics remain justified by their prior cycle. Human
acceptance is recorded separately after the implementation/evidence commits.
