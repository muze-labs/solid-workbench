# Direct model bindings in Contacts and the design example

CYC286 binds the Contacts address-book and recipient lists to the same model
view. The model holds separate queries for the two modes. Workspace state
captures and restores the address-book query through the existing search
action. Refresh still follows source replacement through the existing effect.

The shared design example now binds its fixed-fixture model view directly.
The package guide documents that binding for app authors. The focused checks
exercise filtering, a restored query and selection through the capability.
