# Add web shortcuts with automatic metadata

Active on verified branch `spiral/CYC-20261118-QG24H-278-web-shortcut-discovery`.
The maintainer authorizes the agreed Launcher cycle using the separate Rust
service and explicitly requires configurable cross-origin support. The current
Launcher accepts manual URLs and handles only internal shortcut drops. It reads
an explicitly supplied Workbench RDF manifest, with no automatic web lookup.

The Launcher owns placement, local RDF persistence and rendering. Paste through
Add shortcut is the phone and keyboard equivalent of dropping a link on a screen.
Save the shortcut before discovery. Preserve the original URL and stop a late
lookup from overwriting edits or reviving deleted records. Store the provider
per identity in existing preferences. Use the deployment's same-origin route
when unset. A selected HTTP provider runs remotely through Metro with no
Workbench credentials. Browser app capabilities retain their window transport.
The server supplies cross-origin permission for the Workbench origin.

Use the existing SimplyFlow UI and feedback patterns. Local shortcut edits and
placement survive reload without network. Opening the destination depends on
the destination's availability. A local-only add skips lookup. No new startup
request or dependency. Verify drop, paste, deep link, local-first fallback,
provider selection, cross-origin behavior and download impact. Human acceptance
belongs after evaluation.

Evaluation is ready for maintainer review. IMP-20261118-QG24H-279 records the
implementation. EVD-20261118-QG24H-280 records the passing feature checks, live
Compose tests, throttled phone probe, and the existing Launcher paging timeout
in the combined browser run with an independent pass.
