# Notebook document workflow

Status: Accepted by maintainer; ACC-20261114-QG24H-204 records exact versions.
Earlier Active/pending entries are retained review history. Dedicated branch
spiral/CYC-20261114-QG24H-199-notebook from main db0de64. Continue the agreed
personal-app roadmap; broader embedded-view resilience remains open.

Deliver one open notebook containing ordered rich-text blocks, using the published
Cobalt notebook controller. Support New, Open, Save and Save As for different
notebook documents, preserving recovery data on switching. Add/split/join and
formatting have phone and keyboard controls. Code/image blocks, folders and a
multi-notebook library remain future work.

App boundary: Notebook owns documents, RDF persistence and block structure;
Cobalt owns editing, NotebookController owns cross-block operations. SimplyFlow
owns content markup and feature datasets; no custom DOM list renderer.
Offline: account-scoped native Turtle drafts survive reload and disconnection.
Each local document retains its own recovery entry; uncached remote documents
need a connection. Conditional Pod writes use existing document/Metro APIs and
preserve unknown RDF, identities and conflicts. Never discard unsaved documents
when opening another. Phone: one column, readable native controls and editor.
Accessibility: labelled editors, keyboard movement/split/join plus buttons,
visible focus and save/error status. Download: measure full app/callback graph,
keep authoring assets optional and budgets advisory.

The local prototype/library was inspected before proposing concrete scope.
Maintainer confirmed rich-text blocks, then clarified multiple document load/save
and resumed after a pause. No commit/merge/publication authorized. Evaluate with
native input, structure/reload/recovery, conditional/conflict saves, account
isolation, source/build and full browser checks; manual AT remains distinct.
