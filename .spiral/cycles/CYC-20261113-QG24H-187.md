# Lean runtime downloads and optional authoring sources

Status: Active. The maintainer explicitly confirms “lets do it” after the
measured source-payload gap and proposed scope. Verified branch:
spiral/CYC-20261113-QG24H-187-lean-runtime-sources, from main 0702a85.

Goal: remove inspection-only readable JavaScript from normal startup graphs,
while keeping same-build authored sources separately available for a future IDE.
This deliberately revises the proposed embedded-view resilience priority;
Phase 3 and the unclassified Presenter native-pointer test issue remain open.
The preceding disposable probe measured Workbench 172247→140094 B, Files
148580→125579 B and Presenter 156430→131860 B gzip. These are preliminary
whole-graph/callback build measurements, not behavior verification.

Boundary: packaging/authoring metadata only. Keep SimplyFlow runtime feature
objects, commands/actions/events, templates/styles and build-time View Source.
Do not build an IDE UI or loader, change auth/data policy or add a renderer.
Normal operation must not request optional authoring assets. Preserve both
minified and readable executable variants; source maps remain separate files.

Use Rollup's existing asset emission and file-URL references, with hashed,
static authoring modules carrying strings rather than executing authored code.
No new library, service, app purpose or manual network path. Runtime source
slots identify optional metadata; full source retention moves to those assets.
User authorization supersedes the old always-in-runtime readable-source policy.

Offline/recovery: all existing core loaded/cached data and failure behavior stay
owned by their current libraries. Missing authoring files cannot block startup
or normal tasks. Optional source access needs deployed matching assets; no
cold-offline IDE promise. Phone and accessibility: no new controls or layouts;
verify existing native core workflows, keyboard/focus and phone operation.
Download: measure every full normal app graph plus auth callback and optional
source bytes separately; observe actual cold core-task requests and time. Keep
budget warnings advisory. Tests cover source artifact fidelity and isolation,
normal operation with authoring routes denied, and explicit authoring inspection.

Preserve the existing presentation-link roadmap paragraph and untracked app
priorities document. No commit/merge/push/publication is authorized for this cycle.
