# Adopt the published SimplyFlow lifecycle and binding features

The maintainer asks to start a Workbench cycle once SimplyFlow is published.
The goal is to consume the published package and remove Workbench code whose
job the new library can now do. [Maintainer request](../sources/SRC-20261119-QG24H-296.md)

The verified branch `spiral/CYC-20261119-QG24H-295-simplyflow-adoption` starts
at `d1a6c8e` on authoritative `main`. The roadmap direction continues the
SimplyFlow lifecycle and composition follow-up. The new stable list key
makes it possible to test the deferred row-identity question on Presenter.
Preserve explicit component order and the existing event override contract.

## Confirmed adoption scope

Workbench locks SimplyFlow 0.10.4. The confirmed npm release 0.10.6 specifies
app 0.10.5, bind and state 0.10.3, and model 0.10.4. The current app code still
copies model sources through pass-through effects, walks model effect arrays
for cleanup, wraps app destruction, and bridges Presenter's transformer
context. Presenter caches projected rows by identity and waits for bindings
with a bounded frame loop. The maintainer selects “Proceed with this scope”
after reviewing these gaps. Use reactive model sources and `model.destroy()`, the top-level app destroy hook, mergeable event maps,
live transformer context, stable slide keys and `binding.whenIdle()`. Adopt
each only where the published contract preserves existing behavior.

## Evidence required

- Keep existing app and data-ownership boundaries. Verify preservation of
  cached data, drafts, native RDF, subscription shutdown, offline behavior
  and the existing reconnection and conflict paths.
- Verify Contacts filtering and source replacement. Verify Presenter slide
  reorder, focus, command identity, thumbnail refresh and editor continuity.
  Exercise the phone and keyboard paths with the existing labeled controls.
  Record browser automation and manual assistive-technology evidence separately.
- Run `npm run check` and `npm run test:browser`. Compare complete app graph
  transfer sizes, including the auth callback, and cold phone time to a usable
  task. Keep the existing gzip thresholds advisory and optional authoring
  requests off normal startup.

Baseline `npm run check` passed all 42 source test files and the readable and
minified builds. Production graphs including the callback measured 130547
gzip bytes for Contacts, 163708 for Presenter and 727377 for Documents.
The existing Documents budget warning is advisory.

A disposable test of the actual published browser bundle verified model source
replacement, keyed row reuse, binding completion, transformer app context and
one-shot destruction. It also verified that opting both the event map and its
descriptor into composition preserves required target and type on a partial
action override and leaves the original descriptor intact. Workbench's
integration is recorded in the evaluation below.
