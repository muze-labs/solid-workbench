# The DS extension for Workbench search and menus

Active on verified branch `spiral/CYC-20261118-QG24H-282-ds-extension`.
The maintainer confirms “Ok, then lets do this cycle” after the inventory and
Alloy CSS comparison, and asks to inspect Open UI as additional prior art.
The initial scope extracts compact search and anchored popovers from existing
apps and exposes both CSS and SimplyFlow entry points with working examples.

The suite already has editable theme and list CSS, with search icon markup
duplicated in Contacts, Documents and the catalog. Popover styles live in
the theme, and positioning relies on an authored shared anchor name. There
is no plain HTML entry for the extension. Use the existing named sheets
and build-time template compilation. Keep the suite's runtime datasets so
authors can edit styles in place. The plain HTML build is optional to the apps.
The examples use local fixture data and do not need a Pod. App-owned search,
editing, storage, cache and recovery behavior remain with their existing hosts.

Verify native controls, menu focus and dismissal, distinct anchors, phone
layout, enlarged text, ordinary app regressions and cold download impact.
Keep the extension and examples off the suite's normal request path.
Use the HTML popover and CSS anchor positioning specifications. Treat Open UI
focusgroup and menu elements as research rather than runtime dependencies.

Evaluation is ready for maintainer review. IMP-20261118-QG24H-283 describes
the shared CSS and existing-app migrations. EVD-20261118-QG24H-284 records
the Chrome examples, cold-load measurements, app suite reruns and limits of
the full browser run.

## Prefix revision

The maintainer requests `solid` in place of `muzeSolidDesign`. The cycle
applies `solid` to the extension's JavaScript names and `solid-` to its CSS
classes, properties and markup identifiers. Keep package imports under
`@muze-labs/solid-design`. Verify the app consumers and examples together.

The maintainer also asks the examples to demonstrate semantic markup.
Use native search landmarks, labels, a form, link lists and output. Keep
ARIA only to express behavior native markup does not supply. Verify the
search and status roles in Chrome's accessibility tree.
