# Resumable file-operation boundary

Status: Active, Evaluate, ready for human review. Maintainer confirms the proposed next cycle with “yes”.
Goal: simplify resumable operation/collection reconciliation through Notebook
and Presenter while preserving their different local recovery/deletion policies.
This continues the high-priority library simplification roadmap after shared
DocumentSession and collection browsing. No package publication or drag/drop.
Baseline main 8be29959da40bb4fdb60310f708d8e2973d7479a. Actual branch verified:
spiral/CYC-20261115-QG24H-229-resource-operation-boundary.

Current gap: ResourceLifecycle already owns physical retry/metadata state, but
encodes collection/entry IDs. Both apps duplicate complete -> repair/remove
membership -> sync -> apply local policy -> acknowledge, with acknowledgement
correctly last. Move that shared sequence to a collection-specific bridge;
keep the physical engine independent of collection interpretation. Preserve
current native journal shape and same-store atomic context, including old
unfinished operations. Avoid a second journal and split-write recovery problem.

Guardrails: app purposes/UI stay unchanged. Native local intent and source/
validator checks survive reload/offline/auth failure/lost replies; uncached
resources still require access. Phone/native labelled confirmation/retry/cancel
and keyboard flow remain. No CSS or renderer changes; authored data API sources
remain optional, runtime feature datasets present. Isolate shared implementation
to document graphs and measure complete graphs/cold tasks. Native RDF is primary.

Evaluate: engine-independent RDF context, old journal restore, each remote and
local failure boundary, acknowledgement failure, reload, duplicate retry,
account isolation, unknown native RDF, two real app consumers, and unchanged
Notebook retained drafts versus Presenter purge. Run npm run check and required
browser command; distinguish manual AT/Firefox/live-provider evidence. Review
whether caller assumptions were removed rather than merely moved. Pause if
wire/storage semantics, overwrite policy, app deletion promises or publication
need change. Artifacts SRC230/DES231/IMP232/EVD233. No commits or delivery asked.
