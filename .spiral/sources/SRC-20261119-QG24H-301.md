# Maintainer selects the live Presenter template proof

After accepting CYC295, the maintainer asks for next-cycle options.
Option 1 proposes changing the named Presenter thumbnail template,
rerendering current rows and restoring the original while preserving
selection, keyboard focus, open slide draft and native RDF.
The maintainer replies “Lets go with option 1”.

After the browser probe finds that generated element roots lack a public
template-name marker, the maintainer replies “Scope the SimplyFlow follow-up”.
The separate scope is recorded in the
[SimplyFlow design](../../design/simplyflow-lifecycle-composition-design.md#scoped-follow-up-for-rendered-template-names).
