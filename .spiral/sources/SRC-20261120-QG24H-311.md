# Maintainer confirms the first assistant cycle

The maintainer expressed a preference to begin the assistant after checking
for urgency elsewhere, then approved the proposed scope with “Ok, lets do
that”. The proposal is one optional Suggest topics workflow on a small
Social Bookmarks fixture. It uses a dedicated assistant origin and a mock
model, discloses only selected titles and URLs, and keeps review and
application in the caller. Live credentials, imports and general-purpose
tool calling are outside the scope.

In review, the maintainer distinguishes permission for Bookmarks to send
information to the model from permission for the assistant to call a
Bookmarks capability. The maintainer says “yes, please add it here” to the
proposed reverse-direction proof in CYC310. This accepts the scope revision
for one selection-read capability, with a separate grant.

The maintainer requests the permission UI in each receiving app's iframe
and confirms the proposed inline mock preview with “yes, please”. The
assistant owns approval for model use, and Bookmarks owns approval for
the assistant's selection read. The live credential setup design retains
its top-level origin boundary.

The maintainer says the assistant still needs a top-level tab for its complete
grant list and model selection. Each assistant iframe must coordinate with that
tab because browser storage can be partitioned. This retains the top-level
authority in the design alongside app-owned inline approvals.

The maintainer reports that the Bookmarks read prompt appears to belong to
the assistant. The original placement put Bookmarks' prompt above the
assistant frame inside a dock headed “Assistant”. Present the decision in
a separate Bookmarks dialog inside the Bookmarks frame.

The maintainer asks for the original capability call to continue when the
user approves the read. The maintainer also reports that the Assistant dock
vanishes during the decision and reappears afterwards. Keep the dock visible
behind the Bookmarks dialog while the request awaits a decision.
