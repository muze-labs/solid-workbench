# Maintainer direction for shared library globals

The maintainer asks for all application and module code to use the Muze
library globals without separate imports: Metro, jaqt, oldm and Simply.
They want user-supplied functions to be able to replace the app's own
functions and use those same libraries without imports. They confirm that
the boundary includes shared Workbench modules and app-owned helpers, ask
for a roadmap check, and then say “lets start the cycle”.

The preceding roadmap discussion adds a live apply/remove proof using a
Contacts search function and a shared data helper, checks that already
running callers use the current implementation, and retains optional
version-matched authoring sources. General SimplyFlow lifecycle changes,
live template updates, persisted overrides, remaining model-view migrations,
and shared component adoption have separate roadmap scope.

After reviewing the dependency inventory, the maintainer asks to add the
Launcher shared-helper and Cobalt transformer proofs to the active cycle and
continue. The proofs cover reconstruction, dispatch in existing callers,
restoration and preservation of current state.

The maintainer asks to be consulted on proposed SimplyFlow fixes and selects
“Scope a SimplyFlow follow-up” for app context and live transformer lookup.
