# Confirmed iframe Escape repair

The maintainer first asks to fix dialogs that do not close on Escape when focus
is inside an iframe, then selects roadmap deferral. After CYC151 acceptance and
delivery, the next-cycle discussion proposes this shared repair with existing
save/discard guards, inner-layer precedence and scoped cross-origin cooperation.
The maintainer confirms “lets do that”. This authorizes branch implementation,
not acceptance or Git delivery.

Before product edits, a disposable Chrome probe using the actual Workbench and
Preferences build at baseline main reproduces native Escape leaving Preferences
open; invoking the existing close action closes the same modal. Probe:
/tmp/cyc157-reproduce.mjs. Source inspection finds Account's separate forwarding,
shared host cancel handling and no general child Escape forwarding.
