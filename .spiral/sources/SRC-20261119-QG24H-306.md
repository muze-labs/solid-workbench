# Maintainer selects a dockable app inspector

The maintainer selects the read-only inspector direction and asks for
a sidebar on any top-level app, with an option to open a new window and
a corresponding option to dock it again. The maintainer also asks to adopt
the published SimplyFlow updates, selects “Start closed”, and asks to add
“inspect” in the Preferences dropdown.

During review the maintainer asks the inspector to show the bound data
path, named template, parent navigation and owning component. Source
opens on request. The maintainer confirms linking generated data to the
authored binding that reads its runtime path.

The maintainer asks for inline bounded previews with a floating X and
toggle controls, an icon toolbar and standard dialog close button,
remembered docking, a navigable compact breadcrumb trail, a resizable
dock and a theme-dependent surface. During picking, the pointer changes
and embedded frames dim to identify the inspection boundary. The
maintainer also asks for JSON for Data entries and proposes Turtle for
OLDM values.
