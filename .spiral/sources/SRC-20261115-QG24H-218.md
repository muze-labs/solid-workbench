# Confirmed shared document-session scope

On 2026-11-15, after CYC211 delivery and Spiral core update, the maintainer asks
“next cycle?”. The proposed goal is a shared document save-and-recovery boundary
for Notebook and Presenter, continuing the high-priority library-simplification
roadmap. The concrete gap is duplicated local-write, revision, remote-address,
ETag and baseline coordination, with different app models and switching policies.

The proposed contract preserves app-owned document/index/navigation behavior,
native RDF/account isolation, offline edits, conflicts, missing-validator recovery
and edits during save. Reuse Workspace and existing conditional helpers; retain
the anonymous-RDF bridge; no publication, new UI or sibling implementation.
The maintainer says “yes”, confirming this scope before implementation.

Repository source/API inspection corroborates the duplication in
apps/notebook/src/document.mjs and apps/presenter/src/deck-data.mjs, including
recovery-write queues and nearly parallel save algorithms. Workspace 0.2.2 README
explicitly excludes conditional remote writes/cross-tab ordering. Existing tests
prove materially different lost-creation, per-copy baseline and dirty-open policies.
These are simplification findings, not a claim that either app generally loses data.
