# Maintainer request to adopt the SimplyFlow release in Workbench

On 19 November 2026 the maintainer says they are running publication and
asks to start a new Solid Workbench cycle once the release is available.
They want to update SimplyFlow, remove workarounds that the new release makes
unnecessary and use its new features.

The preceding SimplyFlow review selects model source replacement and cleanup,
stable list keys, binding completion and app-owned destruction. The maintainer
leaves partial event overrides for Workbench and defers new plain-text and
single-attribute binding syntax.

After reviewing the current model, teardown and Presenter workarounds, the
maintainer selects “Proceed with this scope”. The scope excludes runtime
template editing infrastructure and unrelated UI changes.
